# 06 · UAT 测试全流程

## 1. 测试计划

```markdown
### UAT 测试计划
- 测试范围：报表页 / 模块 / 指标清单（明确不测什么）
- 验收标准：数据准确率 100%（核心指标）、性能阈值（首屏<5s/单视觉<3s）、权限穿透 0 缺陷
- 测试周期：起止日期、每轮时长
- 参与角色：业务测试人 / BI 开发 / 数据负责人 / IT 权限管理员
- 环境与数据：测试工作区、数据截止日期、是否用生产快照
- 问题反馈流程：提交渠道 → 定级 → 分派 → 修复 → 回归 → 关闭（含 SLA）
- 准入条件：冒烟通过（能打开、数据已刷新、权限已配置）才进入 UAT
- 准出条件：P0/P1 清零，P2 ≤ 约定数量且有规避方案
```

| # | 模块 | 测试场景 | 筛选条件 | 操作路径 | 预期结果 | 校验方法 | 优先级 |

| TC-03 | 权限 | 大区经理仅见本区数据 | 以 user_a 身份 | 各页检查 + 导出 | 无其他大区数据，导出同样受限 | View as role + 实际账号登录 | P0 |

## 3. 缺陷定级标准（量化，避免扯皮）

| 级别 | 定义 | 示例 | 修复时效 | 回归要求 |
|---|---|---|---|---|
| **P0 阻断** | 数据错误导致决策错误；报表打不开；权限越权泄露 | 金额与源系统差 10%；非本区数据可见 | 4 小时内响应，当日修复 | 全量回归 + 数据重对账 |
| **P1 严重** | 局部数据错误；核心页面超时 > 10s；关键交互失效 | 某维度汇总对不上；钻取不继承筛选 | 1 个工作日内 | 相关模块全回归 |
| **P2 一般** | 非核心口径偏差；格式/单位错误；次要交互异常 | 百分比小数位错；图例顺序乱 | 3 个工作日内 | 用例级回归 |
| **P3 优化** | 体验与美观建议 | 配色、文案、布局微调 | 排入下期 | 无需回归 |

## 5. 验收交付

### 5.1 UAT 验收报告
```markdown
- 测试概况：范围、周期、参与人、用例总数 / 通过数 / 通过率
- 缺陷统计：按级别分布、按模块分布、关闭率
- 遗留问题：编号、级别、影响、规避方案、计划解决时间
- 验收结论：通过 / 有条件通过（列明条件）/ 不通过
- 签字确认：业务方 / 数据负责人 / 项目经理
```

### 5.2 上线确认清单
- [ ] 数据源连接已指向生产，凭据与网关配置正确
- [ ] 刷新计划已配置，首次全量刷新成功，SLA 已约定
- [ ] RLS 角色已发布，已用真实账号验证
- [ ] 工作区权限：查看/成员分工明确，无个人账号直连
- [ ] 指标口径表已签字归档，报表内可见口径说明
- [ ] 性能基线已记录，监控告警已配置
- [ ] 回滚方案：上一版本文件/定义已备份，回滚步骤已演练
- [ ] 用户培训与操作手册已发放
