# 04 · 可视化开发

## 1. 报表架构（三层）

| 层 | 页面 | 作用 | 对象数建议 |
|---|---|---|---|
| L1 总览 | 首页看板 | 3–5 个 KPI 卡片 + 1–2 趋势图 + 1 排名图，回答"好不好" | ≤ 12 |
| L2 分析 | 分模块明细页（销售/库存/财务…） | 多维拆解，回答"为什么" | ≤ 15 |
| L3 明细 | 明细表页 / 钻取页 | 单据级追溯，回答"具体是哪些" | ≤ 8 |

**钻取路径**：总览 KPI → 模块页（按维度钻取）→ 明细页（保留筛选上下文）。钻取页必须显示来源筛选（用 `SELECTEDVALUE` + 卡片/文本），避免用户迷失上下文。

## 2. 页面原型说明模板

```markdown
### 页面：<名称>
- 目标用户 / 决策场景：
- 核心问题（≤3 个）：
- 布局草图（区块描述）：
  | 区块 | 视觉类型 | 字段 | 交互 |
- 切片器：字段 / 默认状态 / 是否同步到整册
- 钻取：来源页 → 本页 → 下钻目标
- 移动端布局：单独排布 or 复用（移动端需单独画布）
```

## 3. 交互逻辑清单

| # | 交互 | 触发 | 影响范围 | 实现 | 备注 |
|---|---|---|---|---|---|
| 1 | 同步切片器 | 期间选择 | 全部页（除明细页） | 视图 → 同步切片器 | 勾选"同步"，不勾"筛选"到钻取页 |
| 2 | 钻取 | 点击柱条 | 跳转明细页并继承筛选 | 钻取字段 + 保留所有筛选 | |
| 3 | 书签切换 | 按钮 | 同页内显示/隐藏图层 | 书签 + 选择窗格 | 书签需关闭"数据"以固定当前筛选 |
| 4 | 自定义 tooltip | 悬浮 | 当前视觉 | tooltip 页（建议 320×240） | tooltip 页内避免重度量值 |
| 5 | 交叉筛选 | 点击图例 | 同页其他视觉 | 编辑交互，默认改为"筛选"或"无" | 卡片图通常设为"无" |

规则：
- 卡片图、KPI 一般**不接受**其他视觉的交叉筛选（设为"无"），否则数字随点击跳动引发误解。
- 每页视觉对象数与交互数量成正比影响渲染时间，超过 15 个必须拆页。
- 钻取页默认隐藏；使用"返回"按钮。

## 4. 视觉规范表

| 项 | 规范 |
|---|---|
| 页面尺寸 | 1280×720（16:9），网格对齐，边距 16px |
| 字体 | 中文「微软雅黑」/「思源黑体」，标题 18–20pt，正文 10–11pt，数字用等宽（Segoe UI / Bahnschrift） |
| 主色 | 1 个主色 + 1 个强调色 + 中性灰阶；分类色 ≤ 6 色，超出用同色系明度递进 |
| 涨跌色 | 中国区默认**涨红跌绿**（与欧美相反），需与用户确认 |
| 数字格式 | 金额：千分位 + 1 位小数，超百万显示"万/亿"单位；百分比 1 位小数；整数不显示小数 |
| 条件格式 | 阈值固定 3 档（好/预警/差），阈值写入口径表，不随刷新漂移 |
| 轴线 | 横向网格线淡灰、纵向不显示；Y 轴起点 0（柱状/折线），起点非 0 需标注 |
| 标题 | 每个视觉必须有明确标题，标题含口径提示（如"销售额（含税，已出库）"） |
| 空态 | 无数据时显示"当前筛选无数据"，不显示空白图 |

## 5. 图表选型

| 目的 | 首选 | 备选 | 避免 |
|---|---|---|---|
| 趋势 | 折线图 | 面积图 | 3D 折线 |
| 比较 | 横向条形图（类别名长时） | 柱状图 | 饼图 > 5 类 |
| 构成 | 堆叠条形 / 树状图 | 饼图（仅 2–3 类） | 双饼图、环形套娃 |
| 分布 | 直方图 / 散点 | 箱线图（需自定义视觉） | |
| 排名 | 条形图 + 排序 | 表格 + 数据条 | 词云 |
| 明细 | 表格 / 矩阵 | | 一个表放 20 列 |
| 地理 | 填充地图（着色） | 气泡地图 | 大量点位的散点地图 |

## 6. 移动端与可访问性

- 移动端：单独"移动布局"画布，纵向单列，只保留 KPI + 1–2 图；隐藏明细大表。
- 可访问性：文字对比度 ≥ 4.5:1；颜色不作为唯一区分（加图标/标签）；设置 Tab 顺序；为视觉对象填 alt text。
- 导出：明细表列数控制在 10 列内以便 Excel 导出；超过则用明细页 + 分层钻取。
